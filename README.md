A free, offline browser app that turns your own photos and a caption into GTA-style cover art: a multi-panel poster with bold lettering and a Vice City sunset or neon grade. Pick one of eight poster layouts — Hero Split, Triple Strip, Feature, Pop-Out Hero (the hero panel breaks out of the frame over the title band), Seven Panel, Slanted Strip, Five Frame, Feature Stack — drop up to five photos into the panels, drag to pan each photo, pin each crop with a face anchor (top / centre / bottom), tag the cast with editable role labels, add a callout quote, a seal stamp and a billing block, put the big title over the art itself, tune one of eight colour grades (Sunset / Neon / Vice / Gold / Teal / Rose / Dusk / Poster Ink), then export a PNG in 1080 × 1080, 1080 × 1350, or 1920 × 1080. Everything runs on your own machine — no uploads, no network requests, no font files. All artwork (sunset sky, sun disc, skyline, palms) is drawn fresh in canvas; nothing is borrowed from any game.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080
