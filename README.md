A free, offline browser app that turns your own photos and a caption into GTA-style cover art: a multi-panel poster with bold lettering and a Vice City sunset or neon grade. Pick one of three poster layouts, drop up to three photos into the panels, drag to pan each photo, tune the zoom and colour grade, then export a PNG in 1080 × 1080, 1080 × 1350, or 1920 × 1080. Everything runs on your own machine — no uploads, no network requests, no font files. All artwork (sunset sky, sun disc, skyline, palms) is drawn fresh in canvas; nothing is borrowed from any game.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080
